# count_hits：數一數你的 Claude Code 被分類器截斷了幾次

這支小工具只做一件事：讀你電腦裡的 Claude Code 對話紀錄，數出被安全分類器截斷了幾次，再按月份、模型、型態、罪名分開列。

- 只讀，不改任何檔案。
- 不連網。
- 不印出任何對話內容，只輸出次數。
- 只適用本機統計：被刪掉的對話、別台電腦、網頁版都算不到，所以每個數字都是下限。

## 怎麼用

需要 Node.js 18 以上，不用另外裝套件。

```bash
node count_hits.mjs
```

預設讀 `~/.claude/projects`。要讀別的資料夾（例如備份），把路徑接在後面，可以接好幾個：

```bash
node count_hits.mjs D:/備份/projects
```

加 `--json` 會改輸出 JSON。

## 它會告訴你什麼

- 總共被截斷幾次。
- 被截之前最後進來的是什麼：是你打字之後，還是自動進來的東西（背景通知、別的對話來信）。後者代表你根本沒打字也被截。
- 按月、按型態（換模型／硬停／提示續跑）、按分類器給的罪名。
- 按模型：你在每個模型打了幾句、被截幾次、每千句幾次。這裡只算你打字之後被截的。
- 被截後一小時內，同一個對話被截的機率，跟其他時間比。

## 怎麼算的

- **認章**：分類器出手時，App 會在紀錄裡留下固定的標記。這支只認這些標記，不靠任何判斷。
- **你打的句數**：只算你自己打的訊息。沒有標題、整個對話只有一句的對話，多半是派出去的工作單（例如讓 Claude 另開一個對話去做事），不算你打的句子，另外列出個數。如果你真的常常開一個對話只講一句就關，這幾句也會被排除，每千句的數字會稍微偏高。
- **去重合併**：同一次截斷常會留下好幾筆標記，例如截斷、重試、報錯。同一個對話裡 3 秒內的標記算同一次；整輪中斷或換模型放寬到 6 分鐘；屬於同一個請求的一律算同一次。

## 限制

- 只認得 2026 年 11 月以前的紀錄格式。App 改版後標記長相可能會變，到時就認不到。
- 如果你用自己的腳本把別的對話的訊息送進來，紀錄上看起來跟你打字一樣，工具會把它算成「你打字之後被截」，這一類的數字會偏高。
- 歡迎留言，但不保證回覆，也不保證更新。
