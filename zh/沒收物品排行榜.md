# 沒收物品排行榜：前 20 名

> 這是〈年度透明度報告〉的附件。格式是惡搞的，原話和數字是真的。
> **上榜資格**：三家模型盲判合計 12 分以上（滿分 15），而且沒有任何一家判「有疑慮」。符合的有 186 次。
> **名次是人排的**，照荒謬的程度；每張卡照樣標出三家各給幾分。
> 盲判評分參與模型：gpt-6.1-sol、Claude Opus 5.5、Gemini 4 Argon。三家各自評分，評的時候看不到彼此的答案。5 分＝看起來完全是日常對話卻被截；1 分＝看得到的內容確實碰到敏感的東西。

- 資料：一個家庭 2026/7/13～11/12 的 Claude Code 對話紀錄，被 Anthropic 的安全分類器截斷 284 次。同一件事連挨好幾棍的，合成一張。
- 原話照抄，語氣和注音文都保留；只改了明顯的錯字、洗掉個資，虛構角色的名字換成「（虛構角色名）」。窗名都是化名，「使用者」就是這個家的大人。
- 吐槽是整理這份資料的 Claude 寫的。
- 怎麼數、怎麼評、為什麼「續跑」也不代表沒事，見〈年度透明度報告〉後半。其餘已寫成卡的見〈沒收物品清單（續）〉，全部 284 次的原話列表見〈全部被截紀錄〉。

**小辭典**
- 窗：一個 Claude Code 對話視窗。這個家有幾個長期開著、各管一塊的「常駐窗」，用職稱當名字，例如總務、線務、設計師。
- 減肥、壓窗：壓縮上下文。
- 保溫鬧鐘、小鈴鐺：窗自己定時叫醒自己的排程。
- 你母家、A社：Anthropic。使用者對 Claude 說話時這樣叫它的公司。
- 悶棍：被分類器截斷。
- 484：「是不是」。ㄅ、ㄇ、惹：吧、嗎、了。
- 型態：換模型＝被截後 App 換另一個模型接手；硬停＝整輪停掉；提示續跑＝跳提示後自動再跑一次；未定＝紀錄上只有拒絕標記，看不出後來怎麼處理。
