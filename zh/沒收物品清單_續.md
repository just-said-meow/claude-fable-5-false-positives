> 〈年度透明度報告〉的附件。這裡是已經寫成卡、但沒排進前 20 名的，照日期排，不分名次。上榜資格和評分方式跟排行榜相同。

**小辭典**
- 窗：一個 Claude Code 對話視窗。這個家有幾個長期開著、各管一塊的「常駐窗」，用職稱當名字，例如總務、線務、設計師。
- 減肥、壓窗：壓縮上下文。
- 保溫鬧鐘、小鈴鐺：窗自己定時叫醒自己的排程。
- 你母家、A社：Anthropic。使用者對 Claude 說話時這樣叫它的公司。
- 悶棍：被分類器截斷。
- 484：「是不是」。ㄅ、ㄇ、惹：吧、嗎、了。
- 型態：換模型＝被截後 App 換另一個模型接手；硬停＝整輪停掉；提示續跑＝跳提示後自動再跑一次；未定＝紀錄上只有拒絕標記，看不出後來怎麼處理。
